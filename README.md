# AI-PriceOptima

## Project Title

AI-PriceOptima — Dynamic Pricing Recommendation System 

## Project Objective

Provide business-friendly, real-time price recommendations using historical sales, inventory and competitor pricing data. The system requires only four user inputs; the backend performs automated feature engineering and returns an AI-driven recommended price.

## Dataset Description

- Location: `dataSet/` directory (examples: `revenue_lift_9pct_30000.csv`, `master_dataset_cleaned.csv`).
- Columns: date/time, product id, price, cost, units sold, stock/inventory, competitor price, category and related fields.
- Notes: datasets contain noise typical of retail data (missing values, outliers); preprocessing and feature engineering are applied in notebooks.

## Technologies Used

- Backend: Python, FastAPI, Uvicorn, Pydantic
- Frontend: React (Vite), JavaScript, CSS
- Data & ML: pandas, numpy, scikit-learn, joblib (XGBoost / LightGBM optional)
- Dev tools: Git, npm, curl

## Model Development Summary

- Exploratory Data Analysis to define KPIs: Revenue Lift, Profit Margin, Conversion Rate, Inventory Turnover.
- Feature engineering: temporal features (day, month, weekend), lag/rolling statistics, inventory ratios, competitor deltas, and interaction terms.
- Model experimentation: evaluated tree-based regressors (XGBoost/LightGBM) using time-based train/test splits; selected model serialized as `pricing_model.joblib` when available.
- A lightweight fallback model is included in `main.py` so the API remains functional for UI testing when a serialized model is absent.

## Backend Implementation (FastAPI)

- Entry point: `main.py` (project root).
- Endpoints:
	- `GET /` — health check (returns a simple JSON message).
	- `POST /predict_price` — main prediction endpoint. Accepts JSON with keys: `cost` (float), `demand` (float), `inventory` (int), `competitor_price` (float). Returns `{ "recommended_price": <float> }`.
- CORS middleware enabled for local frontend calls.
- Model loading example (add to `main.py` to use saved model):

```py
from joblib import load
try:
		model = load('pricing_model.joblib')
except Exception:
		model = _FallbackModel()
```

## Dashboard Implementation (React.js)

- Files: `frontend/src/App.jsx`, `frontend/src/App.css`.
- Layout: two-column card layout — Input Panel (left) and Output Panel (right).
- Inputs: `cost`, `demand`, `inventory`, `competitor_price` (other features auto-generated by backend).
- Actions: `Predict Price` (POST to backend), `Reset` (clear inputs).
- Output: large, bold recommended price, model status indicator, and short explanation.

## Deployment / Execution Approach

1. Start the backend (project root):

```bash
uvicorn main:app --reload
```

2. Start the frontend (in `frontend/`):

```bash
cd frontend
npm install
npm run dev
```

3. Open the Vite URL (usually `http://localhost:5173`) and use the dashboard.

## API Usage Examples

Example fetch from the frontend or any client:

```js
fetch('http://127.0.0.1:8000/predict_price', {
	method: 'POST',
	headers: { 'Content-Type': 'application/json' },
	body: JSON.stringify({ cost:100, demand:80, inventory:40, competitor_price:110 })
})
.then(r => r.json())
.then(data => console.log(data.recommended_price))
```

Example curl call:

```bash
curl -X POST http://127.0.0.1:8000/predict_price \
	-H 'Content-Type: application/json' \
	-d '{"cost":100,"demand":80,"inventory":40,"competitor_price":110}'
```

## Key Outputs & Results

- API returns JSON: `{ "recommended_price": <float> }`.
- Frontend displays the recommended price (currency shown in UI) and a brief explanation.
- Sample KPI outcomes from analysis: revenue lift ~10.8%, profit margin improvement ~4.1%, inventory turnover improvement ~7.8% (results from notebook simulations and backtests).

## How to Use in a Real-World Scenario

Business users open the dashboard, enter four simple inputs (cost, demand, inventory, competitor price) and receive an AI-driven price recommendation. The backend can be extended to ingest live inventory and competitor feeds and to retrain models regularly with new sales data for continuous improvement.
